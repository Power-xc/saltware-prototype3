01 파우컴퍼니 · 파우더룸

2024.06 보도

과제
뷰티 플랫폼 파우더룸을 운영하며 일본 서비스(파우더룸 재팬)로 넓히는 중이었고, AWS 환경은 자체적으로 운영해 왔습니다.
수행
운영 중인 AWS 환경을 점검해 성능 개선과 불필요한 서비스 비용 최적화 방안을 제안하고 적용했습니다. 글로벌 서비스 확대에 맞춘 보안 아키텍처를 설계 · 구축하고, 운영은 매니지드 서비스로 이어서 맡았습니다.
결과
파우컴퍼니는 보안 강화 조치로 사용자가 더 안전하게 서비스를 이용할 수 있게 됐다고 밝혔습니다.

02 비엔투스 · 램블러

2024.11 보도

과제
2012년 출시한 등산 앱 램블러의 데이터베이스에서 리소스가 비효율적으로 쓰이고 있었습니다.
수행
데이터 환경을 점검한 뒤 데이터베이스를 Amazon Aurora MySQL로 전환하고 최적화했습니다. 마이그레이션 중 생길 수 있는 리스크를 미리 분석해 줄이는 방안을 함께 냈습니다.
결과
비엔투스는 DB 마이그레이션으로 리소스를 최적화하고 성능 개선과 비용 절감을 이뤘다고 밝혔습니다.

03 코드프레소

2024.05 보도

과제
개발자 역량 평가 · 교육과 채용 플랫폼을 제공하는 HR SaaS 기업으로, AWS 도입으로 서비스를 고도화하려 했습니다.
수행
사전 파일럿 테스트로 문제를 미리 걸러 내고, 보안과 효율성에 맞춘 AWS 인프라를 구축했습니다.

적용 기술

  • AWS
  • Amazon Aurora MySQL
