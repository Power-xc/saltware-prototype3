공개 자료 1건

백패커(idus) 사례는 2026.08.26 보도 내용입니다. 나머지 셋은 고객사명을 공개하지 않은 수행 영역입니다.

클라우드 · AWS의 다른 사례

트래픽 성장 구간의 이전과 확장 운영 서비스 안정화와 비용 최적화 규제 환경의 보안 구성과 운영

ISMS-P 103개 핵심 항목을 기준으로 AWS 설정을 자동 점검하는 SCR을 AWS 마켓플레이스로 공급했습니다. 기존 유사 점검 서비스가 사전 협의부터 결과까지 통상 한 달 넘게 걸리던 진단을, 계정 권한에 동의하면 30분 안팎에 받아 봅니다.

  • 진단 결과까지(기존 유사 서비스 통상 1개월 이상)

    30분 안팎

  • 자동 점검 기준 · ISMS-P 핵심 항목

    103개

  • AWS 마켓플레이스로 공급

    2026.08

01 과제

AWS 환경이 ISMS-P 기준에 맞는지 확인하는 보안 점검은, 기존 유사 서비스에서 사전 협의부터 결과 도출까지 통상 한 달 넘게 걸렸습니다.

02 수행

ISMS-P 103개 핵심 항목을 오픈소스 클라우드 보안 도구 Prowler 기반의 점검 규칙으로 옮긴 SCR을, 백패커에 AWS 마켓플레이스로 공급했습니다. 계정 권한에 동의하면 별도의 사전 절차 없이 AWS 설정을 자동으로 훑습니다.

03 결과

진단 결과는 30분 안팎, 짧게는 수십 분 안에 나옵니다. 이 내용은 2026년 8월 26일 아이티데일리가 보도했습니다.
