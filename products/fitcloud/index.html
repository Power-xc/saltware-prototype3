FitCloud 를 이루는 셋

통합 빌링을 맺은 AWS 계정은 Cloud Center 와 Support Desk 를 씁니다. 운영까지 맡기시려면 CarePack 을 더합니다.

01비용 · 사용량 포털

문제계정이 늘수록 요금이 어디서 나오는지 흐려집니다

FitCloud Cloud Center

솔트웨어가 직접 개발한 비용 · 사용량 포털입니다. 모든 AWS 계정의 사용량과 리소스 현황을 한곳에서 보고, 여러 리전과 계정을 로그인을 바꾸지 않고 확인합니다.

  • 서비스별 사용 현황을 월간 · 일간으로 나눠 추이를 비교합니다.
  • RI · Savings Plans 활용률을 보고, 사용 패턴에 맞는 구매 추천을 받습니다.
  • 비용 증감 알람과 RI 미사용 알림을 걸고, 주간 비용 리포트를 자동으로 받습니다.

02기술지원 창구

문제AWS 를 쓰다 막히면 어디에 물어야 할지 모릅니다

Support Desk

AWS 를 쓰면서 필요한 가이드와 기술 지원 요청을 티켓으로 받아 관리합니다. 웹 · 모바일 · 이메일로 접수하고 한국어로 지원합니다.

  • 요청마다 처리 상태를 확인하고 이력을 남깁니다.
  • CarePack Standard 티어부터 계정 · 빌링 · 기술 문의의 AWS 케이스를 대신 엽니다.
  • 2025년 2월 생성형 AI 어시스턴트를 붙였습니다. 문제 분석과 해결책 초안을 AI 가 먼저 만들고, 개인 식별 정보와 API 키 같은 민감 정보는 Amazon Bedrock 가드레일로 가립니다.

03AWS 운영 관리 · MSP

문제AWS 를 직접 운영하고 지켜볼 사람이 없습니다

CarePack

솔트웨어의 AWS 운영 관리(MSP) 상품입니다. AWS 분야별 전문가가 전담하고, 장애가 나면 핫라인으로 전담 엔지니어에게 바로 연락합니다.

  • Basic · Standard · Advanced · Enterprise 네 티어에서 맡길 범위를 고릅니다.
  • AWS Personal Health Dashboard 이벤트를 안내하고, 구성을 바꿀 때 가이드와 설정을 돕습니다.
  • 운영 기록은 솔트웨어가 직접 만든 통합 운영 플랫폼 CloudOps 에 쌓입니다.

할인

Support Desk

빌링 포털

리포트

주간 리포트

당월 누적 사용액, RI 로 절감한 금액, CloudFront 절감액을 계정 · 서비스별로 받습니다.

CarePack 은
네 티어로 나뉩니다

원화 빌링 · 빌링 포털 · 주간 비용 리포트 · Support Desk 는 네 티어에 모두 들어갑니다. 위 티어로 갈수록 점검 · 구축 지원 · 운영 대행 항목이 늘어납니다.

  • 01BASIC

    Basic

    청구와 문의 창구부터 맡깁니다.

    • 사용료 선납 · 월별 차감

  • 02STANDARD

    Standard

    • AWS 케이스 오픈 대행
    • 기본 리소스 구성 지원

    Advanced

통합 운영 플랫폼OUR PLATFORM

CloudOps

쌓인 장애와 해결 사례를 데이터베이스로 두고, 표현이 달라도 원인이 비슷한 과거 사례를 AI 의미 검색으로 찾습니다. 암호화 · 네트워크 접근제어 · 퍼블릭 액세스 차단처럼 사고로 이어질 수 있는 설정 변경을 감지하고, 승인된 변경이 끝나면 구성 기준선을 자동으로 갱신합니다.

AWS 도입 · 운영 서비스 보기
  • ITSM ITIL 4 기준 IT 서비스 관리
  • CMDB AWS 구성 정보 관리
  • FinOps 클라우드 비용 관리
  • AIOps Amazon Bedrock 기반 운영 자동화

FAQ

FitCloud 를 쓰기 전에
자주 묻는 질문

통합 빌링과 CarePack 을 검토할 때 먼저 나오는 항목입니다.

FitCloud 서비스 소개서 요청
FitCloud 는 솔트웨어의 클라우드 브랜드입니다. 솔트웨어가 제공하는 AWS 서비스가 이 이름으로 나가고, 계약과 청구도 솔트웨어가 합니다. AWS 도입 · 이전 · 운영 서비스의 범위는 클라우드 · AWS 사업 지면에 정리돼 있습니다.
고객의 AWS 계정을 솔트웨어 계정과 통합해, AWS 사용료를 달러로 직접 결제하지 않고 솔트웨어에 원화로 냅니다. 세금계산서를 받고 사용료 선납과 월별 차감도 됩니다. fitcloud.co.kr 안내 기준으로 링크 자체에 붙는 별도 수수료는 없습니다.
청구와 문의 창구만 필요하면 Basic, 비용 · RI 일일 점검과 케이스 오픈 대행까지면 Standard, 월간 리포트 · 비용 최적화 점검 · 전담 인력이 필요하면 Advanced 입니다. 24×7 관제와 OS · 보안 패치 같은 운영 대행까지 맡기시려면 Enterprise 티어입니다.
AWS 책임 공유 모델을 따릅니다. FitCloud 공개 SLA 는 MFA 적용, 최소 권한 IAM, CloudTrail 기록, S3 퍼블릭 접근 차단, 중요 데이터 백업을 고객 책임으로 두고, 솔트웨어는 제어할 수 있는 AWS 리소스의 문제 해결을 맡습니다. AWS 데이터센터 인프라의 장애는 AWS 서비스 수준 계약을 따릅니다.
FitCloud 공개 SLA 문서에 심각도 네 단계(운영 시스템 중단 · 운영 시스템 손상 · 시스템 손상 · 일반 지침)별 응답 목표가 있습니다. 정상 운영 시간은 평일 9시부터 18시이고, 24시간 365일 긴급 지원은 추가 계약을 맺은 경우에만 제공합니다. 적용 기준은 계약에서 확정합니다.
지금은 솔트웨어 운영 조직이 CarePack 운영에 쓰는 플랫폼입니다. 2026년 9월 보도 기준으로 연내 전 고객사로 적용을 넓히고, AWS 파트너사와 기업 고객 대상 외부 공급은 검토 단계입니다.
