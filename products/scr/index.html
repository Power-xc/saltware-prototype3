PRODUCT · SCR

AWS 보안 점검을
권한 동의 한 번으로 시작합니다

SCR(Security Compliance Review)은 솔트웨어가 개발한 AWS 보안 점검 서비스입니다. ISMS-P 핵심 103개 항목을 기준으로 AWS 설정을 자동으로 점검하고, 계정 권한 사용에 동의하면 30분 안팎에 결과 리포트가 나옵니다.
위험도가 높은 항목에는 AWS 서비스로 고치는 표준 운영 지침이 붙고, 고치는 일은 솔트웨어 엔지니어가 이어서 도울 수 있습니다.

AWS 보안 점검 상담기술 자료 요청

ISMS-P 핵심 103개 항목 · 결과까지 30분 안팎(2026.08 보도 기준) · AWS 마켓플레이스 프라이빗 오퍼 · 고도화 버전 2026.04

103개

ISMS-P 핵심 점검 항목

KISA 정보보호 및 개인정보보호 관리체계(ISMS-P 2023) 인증 기준에서 AWS 설정으로 확인하는 항목입니다.

30분 안팎

권한 동의 뒤 결과까지

짧게는 수십 분입니다. 기존 유사 점검은 사전 협의부터 결과까지 통상 1개월 이상이 걸렸습니다(2026.08 보도 기준).

3개 영역

점검 범위

사용자 권한 · 접근 통제, 데이터 암호화 · 보안 관리, 장애 · 침해 사고 대응과 재해복구입니다.

2026.04

이런 상황이라면

AWS 위에서 서비스를 키우는 회사가 보안 점검에서 되풀이해 겪는 일입니다.

01 / 0302 / 0303 / 03
01 점검 한 번에 한 달이 걸립니다 범위를 협의하고 자료를 모은 뒤 전문가가 분석하는 방식이라, 사전 협의부터 결과까지 통상 한 달 넘게 걸립니다.

03 서비스가 늘수록 설정이 흩어집니다 계정과 서비스가 늘어나면 흩어진 보안 설정을 같은 기준으로 보기 어렵고, 인증에 낼 증적도 따로 모아야 합니다.

AWS 환경을 분석하는 과정을 AI 로 자동화했습니다. 점검 규칙은 오픈소스 클라우드 보안 도구 Prowler 를 바탕으로 합니다. 어떤 항목을 먼저 고칠지는 리포트의 위험 등급과 운영 지침을 보고 고객이 정하고, 필요하면 솔트웨어 엔지니어가 함께 봅니다.
표준 운영 지침대로 직접 고치셔도 되고, 솔트웨어 엔지니어가 참여하는 프로페셔널 서비스(ProServ)로 보안 컨설팅 · AWS 아키텍처 최적화 · 정기 보안 리뷰와 고도화 리포트 · 취약점 개선을 맡기실 수 있습니다. 운영까지 맡기시면 솔트웨어의 클라우드 운영 서비스 FitCloud 로 이어집니다.
지금은 점검할 때마다 리포트를 받는 방식입니다. 보안 점수 대시보드, 주간 · 월간 · 분기 단위 자동 스캔, 이전 점검 대비 개선 완료율과 잔존 위험 표시, ISMS 인증 심사용 증적 자동 수집은 추가할 계획으로 발표했습니다(2026.08).
AWS 마켓플레이스에서 프라이빗 오퍼로 계약합니다. 기업별 견적을 받아 마켓플레이스에서 계약한 뒤 점검을 시작합니다. 견적은 상담에서 안내합니다.
