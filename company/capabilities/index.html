기술 역량의 범위를
꾸준히 넓혀왔습니다

클라우드에서 출발해 DevOps와 마이그레이션, 데이터와 오픈소스까지 전문 영역을 확장했습니다.

2014

2014 2026

  1. 2014

    AWS 파트너 시작

    AWS와의 파트너십을 시작하며 클라우드 사업의 기반을 마련했습니다.

  2. 2018

    AWS Financial Services Competency

    금융 산업에 필요한 클라우드 전문 역량을 AWS로부터 인정받았습니다.

  3. 2020

    AWS DevOps Competency

    DevOps 환경 구축과 운영 자동화에 필요한 AWS 전문 역량을 확보했습니다.

  4. 2022

    KCSP

    클라우드 서비스 제공 역량을 기반으로 사업 영역을 지속적으로 확대했습니다.

  5. 2024

    AWS Migration Competency

    기업의 클라우드 전환을 지원하는 AWS 마이그레이션 전문 역량을 확보했습니다.

  6. 2026

    Red Hat Premier Partner

    Red Hat 기반 기술 역량과 파트너십을 바탕으로 오픈소스·자동화 영역의 전문성을 강화하고 있습니다.

기준일 2026.08 · 출처 AWS 파트너 디렉터리 · 연도가 확인되지 않은 인증은 아래 목록에 정리했습니다.

PARTNERSHIP

기술 파트너십

글로벌 기술 기업과의 파트너십을 기반으로 클라우드·데이터·보안 분야의 전문성을 확장하고 있습니다.

  • 01

    AWS

    다양한 AWS Competency와 Service Delivery 역량을 기반으로 클라우드 구축과 전환, 운영을 지원합니다.

  • 02

    Red Hat

    Red Hat 파트너십을 기반으로 기업의 오픈소스·자동화 환경 구축을 맡습니다. RHEL·OpenShift·Ansible Automation Platform 을 다룹니다.

  • 03

    Databricks

    Databricks 파트너십을 기반으로 기업의 데이터·AI 활용 환경 구축을 지원합니다.

  • 04

    SailPoint

    SailPoint 파트너십을 기반으로 기업의 아이덴티티 및 접근 관리 환경 구축을 수행합니다.

  • 05 KCSP

    KCSP

    클라우드 서비스 제공 역량을 바탕으로 안정적인 클라우드 운영 환경을 지원합니다.

기준일 2026.08 · 등급은 공식 디렉터리에서 확인되는 것만 적습니다.

솔트웨어는 AWS 클라우드 운영, 데이터 플랫폼, 업무 AI, 계정·권한 보안, 엔터프라이즈 오픈소스, 업무 포털 사업을 수행합니다. 사업별 상세 내용과 문의 창구는 아래에서 확인할 수 있습니다.
