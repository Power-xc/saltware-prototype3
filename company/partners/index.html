PARTNERS

솔루션 22종

벤더 17곳의 제품과 솔트웨어가 직접 만든 서비스 5종입니다. 고객의 환경에 맞는 제품을 함께 고릅니다.

  • Database & Data Platform

    AWS 환경에서 Oracle 호환성과 고가용성을 지원하는 PostgreSQL 기반의 엔터프라이즈 데이터 플랫폼입니다.

  • Data & Analyics

    Strategy One은 AWS 환경에서 생성형 AI와 전통 BI를 완전히 통합한 데이터 분석 플랫폼입니다.

  • Data & Analyics

    AWS 환경에서 정형·비정형 데이터를 손쉽게 분석하고, AI 기반 자동 시각화와 보고서 생성을 통해 데이터 기반 의사결정을 가속화합니다.

  • Security & Protection

    침입 방지·워크로드·엔드포인트 등 전방위 보안을 제공하며, 규제 준수와 글로벌 환경에서 안정적·안전한 운영을 지원

  • Database & Analytics

    문서 기반 아키텍처로 확장성과 유연성을 제공하고, 글로벌 분산 환경에서 안정적·안전한 데이터 관리를 지원

  • K8s Optimization

    Kubernetes 환경의 리소스 사용 패턴을 분석해, 성능 저하 없이 최적화를 실현하는 클라우드 진단 서비스

  • Networking & Security

    보안·네트워킹을 단일 SaaS 플랫폼으로 제공해 글로벌 기업의 분산 환경에서 안정적이고 안전한 연결 지원

  • DevOps & CI/CD

    AWS 환경에서 코드·CI/CD·보안·협업을 통합, 자체 관리형 AI 배포로 규제와 생산성 확보

  • API Gateway & Traffic

    Kubernetes 환경에서 안정적·확장 가능한 트래픽 라우팅과 로드 밸런싱, 보안을 제공하는 인그레스 관리 솔루션

  • Cyber Protection

    데이터 백업부터 랜섬웨어 방어, 재해 복구까지 업무 연속성을 위한 올인원 보안·복구 기능 제공

  • Database Platform

    유연한 확장성과 고속 처리 성능을 통해 실시간 애플리케이션, AI, 모바일 서비스에 최적화된 데이터 운영 지원

  • API & Integration

    API 트래픽 제어부터 인증·로깅까지, 마이크로서비스 연결을 안전하고 유연하게 지원

  • Backup & DR

    다양한 환경의 워크로드를 보호하는 통합 백업·복구 플랫폼으로, 랜섬웨어 대응과 신속한 데이터 복구를 지원

  • Observability

    클라우드 인프라, 애플리케이션, 로그를 실시간 모니터링 및 분석하는 SaaS 기반 모니터링 플랫폼

  • Data

    클라우드 기반의 데이터 웨어하우스 플랫폼으로 데이터 저장, 처리, 분석을 하나의 통합된 서비스로 제공

  • DevOps

    AWS 기반 쿠버네티스 설치, 오픈소스 연동, 복잡한 설정 및 관리, 보안, 성능 최적화 등 패키지화된 서비스 제공

  • AI

    생성형 AI 를 쓰는 과정에서 입력 데이터로 기밀이 나가는 경로를 차단하는 보안 필터링 솔루션. 2026년 4월 Databricks AI Days Seoul 에서 공개 시연했습니다.

  • AI

    Sapie-Lake(데이터 연결 · 관리)와 Sapie-Agent(AI 에이전트)를 합친 통합 플랫폼입니다. 답변의 근거를 함께 보여 주고, 기업의 접근 권한과 보안 정책에 따라 AI 이용을 통제합니다. 2026년 9월 정식 출시했습니다.

  • AI

    데이터 조회 · 분석과 문서 질의응답(RAG)을 이어 답하고, 여러 전문 에이전트가 역할을 나눠 협업하도록 작업을 조율합니다. NIPA AI 에이전트 실증 과제에서 에이전트 층을 맡습니다.

  • Security

    클라우드 기반 통합 아이덴티티 관리 시스템

  • Security

    실시간 네트워크 보안, 위협 탐지 및 자동 대응

  • Data

    클라우드 환경에서 데이터 스트리밍과 실시간 처리를 위한 Apache Kafka 기반의 SaaS 데이터 플랫폼
