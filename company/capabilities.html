기술 역량

TRACK RECORD

기술 역량의 범위를
꾸준히 넓혀왔습니다

클라우드에서 출발해 DevOps와 마이그레이션, 데이터와 오픈소스까지 전문 영역을 확장했습니다.

2014

2014 2026

  1. 2014

    AWS 파트너 시작

    AWS 파트너가 되어 클라우드 사업을 시작했습니다.

  2. 2018

    AWS Financial Services Competency

    금융 산업에 필요한 클라우드 전문 역량을 AWS에서 인정받았습니다.

  3. 2020

    AWS DevOps Competency

    DevOps 환경 구축과 운영 자동화 분야에서 AWS 컴피턴시를 받았습니다.

  4. 2022

    KCSP

    리눅스 재단과 CNCF가 운영하는 쿠버네티스 서비스 인증기업(Kubernetes Certified Service Provider) 자격을 얻었습니다.

  5. 2024

    AWS Migration Competency

    기업의 클라우드 전환 분야에서 AWS 마이그레이션 컴피턴시를 받았습니다.

  6. 2025

    AWS AI Services Competency

    생성형 AI 컴피턴시가 개편된 뒤의 심사 기준으로 컨설팅 부문 인증을 받았습니다. AWS 컴피턴시가 네 분야가 됐습니다.

  7. 2026

    Red Hat Premier Partner

    레드햇 파트너 등급 가운데 최상위 등급입니다. RHEL · OpenShift · Ansible 기반의 오픈소스 · 자동화 사업을 넓히고 있습니다.

  8. 2026

    AWS MSP · Databricks DPP

    AWS 매니지드 서비스 프로바이더(MSP) 프로그램 인증과 Databricks 공동 딜리버리 프로그램(DPP) 자격을 같은 달에 얻었습니다.

기준일 2026.09 · 출처 AWS 파트너 디렉터리, 각 인증 발표 보도 · 연도가 확인되지 않은 인증은 아래 목록에 정리했습니다.

AWS CERTIFICATIONS

AWS 파트너 전문성 10개 영역

산업별 전문성부터 구축·운영 역량까지, AWS 파트너 프로그램 전반에서 인정받은 영역입니다.

  • 파트너 등급 Advanced Tier Services
  • 컴피턴시 Financial Services Competency
  • 컴피턴시 DevOps Competency
  • 컴피턴시 Migration and Modernization Competency
  • 프로그램 AWS Public Sector Solution Provider
  • 서비스 딜리버리 AWS Control Tower Delivery
  • 서비스 딜리버리 Amazon CloudFront Delivery
  • 서비스 딜리버리 Amazon EC2 for Windows Server Delivery
  • 서비스 딜리버리 Amazon RDS Delivery
  • 프로그램 AWS Well-Architected Partner Program

기준일 2026.09 · 출처 AWS 파트너 디렉터리 · 자격 명칭은 AWS 표기를 따릅니다. AI Services 컴피턴시 · Amazon EKS Delivery · MSP 배지는 벽에 아직 없습니다.

PARTNERSHIP

기술 파트너십

글로벌 기술 기업과 파트너십을 맺고 클라우드·데이터·보안 분야로 전문성을 넓혀 왔습니다.

  • 01

    AWS

    Advanced Tier Services 파트너이자 MSP 프로그램 인증 기업입니다. 금융 서비스 · DevOps · 마이그레이션 · AI 서비스 네 분야의 AWS 컴피턴시를 보유하고 클라우드 구축과 전환, 운영을 맡습니다.

  • 02

    Red Hat

    2026년 3월 레드햇 파트너 최상위 등급인 Premier Partner로 선정됐습니다. RHEL · OpenShift · Ansible Automation Platform으로 오픈소스 · 자동화 환경을 구축합니다.

  • 03

    Databricks

    2026년 9월 Databricks와 데이터 · AI 프로젝트를 함께 수행하는 공동 딜리버리 프로그램(DPP) 자격을 얻었습니다. 레이크하우스 구축부터 AI 에이전트 개발까지 맡습니다.

  • 04

    Starburst

    2026년 8월 전략적 파트너십을 맺었습니다. 데이터를 외부로 옮기기 어려운 공공 · 금융 고객에게 온프레미스 데이터 플랫폼 Starburst Enterprise를 공급합니다.

  • 05

    SailPoint

    SailPoint 파트너로 기업의 아이덴티티 · 접근 관리 환경을 구축합니다.

  • 06 KCSP

    KCSP

    2022년 리눅스 재단과 CNCF가 운영하는 쿠버네티스 서비스 인증기업(Kubernetes Certified Service Provider) 자격을 얻었습니다.

기준일 2026.09 · 등급은 공식 디렉터리에서 확인되는 것만 적습니다.
